# Documentação — Destravaí

Este diretório organiza o contexto do projeto para leitura humana e para IAs.

Comece por:

1. `ai-context.md` — resumo curto do produto, stack, regras comerciais e riscos.
2. `audits/` — auditorias e resumos de melhoria.
3. `operations/` — planos de implementação, organização e runbooks.

Regra: documentos antigos ou conflitantes devem ir para `archive/` antes de serem apagados.
